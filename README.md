# 딱 한 곡만 · 예리의 연습실

외부 패키지·API 키 없이 실행되는 HTML/CSS/Canvas/Web Audio 이야기형 게임입니다. 스마트폰 메시지에서 시작해 방 탐색, 압박, 피아노 독백, 헤드폰 속 작은 일탈로 이어집니다. 첨부된 방 이미지의 낮은 해상도와 차분한 팔레트를 참고해 연습실을 직접 그렸습니다.

## 실행과 검사

```sh
cd /workspace/deachung
python3 -m http.server 8000 --bind 0.0.0.0
```

```sh
node --check engine.js
node --check game.js
node tests/game.test.cjs
```

정적 파일이므로 GitHub Pages에서는 `main`의 `/ (root)`로 배포할 수 있습니다. `engine.js`와 `assets/`의 두 MP3도 함께 배포해야 합니다. 소리는 브라우저 정책상 첫 클릭이나 키 입력 뒤 활성화됩니다. 상단 버튼으로 소리를 켜거나 끌 수 있습니다.

## 진행

- 엄마의 메시지가 차례대로 도착합니다. 긍정 답변 또는 침묵으로 방에 들어갑니다. 직접 쓴 말은 전송되지 않고 입력창에 남습니다.
- 감시카메라, 소파, 헤드폰, 문, 시계를 눌러 살펴봅니다. 피아노를 누르면 건반 화면으로 전환됩니다. 시계는 실제 플레이 1분을 게임 속 30분으로 환산합니다.
- 방에 들어온 지 30초에 선생님의 메시지가 도착합니다. 알림 이후 30초 동안 읽지 않으면 문 두드림이 시작되고, 그 뒤 10/20/30초마다 말이 거칠어집니다. 40초가 되면 엄마 메시지가 강제로 열리며, 마지막 메시지 뒤 암전·게임오버가 이어집니다.
- 알림 뒤 피아노에 앉으면 압박 타이머가 멈추고, 화면 명암과 독백이 반복됩니다. 이미 앉아 있을 때 알림이 와도 같은 흐름으로 이어집니다. 메시지를 먼저 읽은 경우에도 피아노에 앉아 다음 단계로 진행할 수 있습니다.
- 피아노에서 일어난 뒤 헤드폰을 누르고 `yes`를 선택하면 음악 플레이어가 열립니다. 60초 동안 Space 또는 레인 터치로 내려오는 일반 음표를 연주합니다. 10/20/30/40/50초에 판정선에 닿는 붉은 음표는 피해야 합니다. 붉은 음표를 누르면 노크·알림과 함께 음악이 작아지고, 5회 누르면 게임오버가 됩니다. 일반 음표를 놓쳐도 게임오버되지 않습니다. 120BPM에 맞춰 초반에는 0.5초 간격의 정박, 중반에는 엇박자, 후반에는 0.25초 간격의 짧은 연타가 섞입니다. 판정 범위는 ±160ms(정확한 판정 ±65ms), 화면에 보이는 낙하 시간은 1.65초입니다. 붉은 음표 앞뒤에는 안전 간격을 둡니다.
- 60초를 버티면 임시 엔딩: “이 한 곡은, 내가 골랐다.” 재시작할 수 있습니다.

## 조작과 표현

마우스·터치로 물체 및 버튼을 선택합니다. Tab/Enter로도 조작할 수 있습니다. 피아노는 A S D F G H J K, 리듬게임은 Space, 일시정지는 P입니다. Escape로 물체 설명·스마트폰을 닫거나 피아노에서 일어납니다. 탭을 떠나거나 창이 포커스를 잃으면 자동으로 멈추며, 숨겨진 시간은 사건 타이머에 더하지 않습니다. 엄마에게 쓰는 입력창에서는 단축키가 작동하지 않습니다.

불안 표현은 빠른 섬광 대신 느린 밝기 변화와 겹치는 텍스트를 사용합니다. 상단 ‘동작 줄이기’와 OS의 동작 줄이기를 지원합니다. 문 두드림은 사용자가 제공한 MP3(`assets/door-knock.mp3`, 약 2.45초)를 사용합니다. 선생님의 노크와 리듬게임 방해음표 오입력에 같은 음원을 재생하며, 음소거·일시정지·재시작을 따릅니다. 파일 로드 실패 시 합성 노크로 대체됩니다. 리듬게임은 사용자가 제공한 「The Finish Line - Televisions」의 첫 60초를 재인코딩 없이 잘라 사용합니다(`assets/the-finish-line-televisions.mp3`). 플레이어에서 미리 불러오고, 디코딩이 끝난 뒤 음악과 게임을 동시에 시작합니다. 음악 시계를 기준으로 노트 진행을 맞추며, 일시정지·음소거·방해음표에 따른 볼륨 감소·게임오버·재시작을 지원합니다. 음원 로드에 실패하면 게임을 시작하지 않고 재시도를 안내합니다. 기존 120BPM 노트 패턴은 유지하며 곡의 실제 박자를 분석한 전용 채보는 아닙니다. 나머지 효과음·피아노는 자체 합성이며, 실제 문자 전송이나 외부 데이터 수집은 없습니다.

`engine.js`: 결정적 이야기/타이밍/리듬 상태, `game.js`: UI·사운드·도트맵, `tests/game.test.cjs`: 타이밍과 성공/실패 분기 검사.
