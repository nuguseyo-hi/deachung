# 딱 한 곡만
순수 HTML/CSS/JavaScript와 Canvas, Web Audio로 만든 72초 리듬게임입니다. 외부 패키지·음원·API 키가 필요 없습니다.

## 실행
```sh
cd /workspace/deachung
python3 -m http.server 8000 --bind 0.0.0.0
```
브라우저로 서버를 열거나 `index.html`을 직접 여세요. 시작 버튼을 눌러야 브라우저 오디오가 활성화됩니다.

Space: 단타/홀드, P: 일시정지. Tab/Enter로 모든 버튼을 사용할 수 있고 터치로 레인을 누를 수도 있습니다. 초록 시간에만 노트가 나오며, 노랑 예고 뒤 빨간 시간에는 손을 떼세요. 5회 들키면 종료, 72초를 버티면 엔딩입니다. 노트당 Perfect 1,000점 / Good 600점, 판정 범위 75ms / 180ms. 홀드 도중 손을 떼면 Miss. 연타와 무관하게 실제 곡 시간이 흘러야 완주합니다. 탭을 떠나면 자동으로 일시정지합니다.

## 파일
- index.html: 화면과 접근 가능한 컨트롤
- style.css: 반응형 픽셀풍 UI
- game.js: 판정, 감시 주기, 오리지널 합성 비트, 장면 렌더링, 이야기
- assets/: 향후 정식 사용 허가를 받은 `black-keys-rock.mp3`를 둘 위치. 현재는 사용하지 않으며 120BPM/72초 차트에 맞춰 연결 필요.

현재 음원은 쇼팽의 실제 녹음이나 편곡이 아닌 간단한 자체 합성 비트입니다. 기획의 곡명은 대사에서 ‘흑건’으로 유지했습니다(통상 흑건은 Op.10 No.5).
