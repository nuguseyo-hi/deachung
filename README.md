# 딱 한 곡만 · 예리의 연습실

HTML/CSS/Canvas/Web Audio로 만든 이야기형 픽셀 게임입니다. 외부 패키지·API 키 없이 실행됩니다. 스마트폰 도입부, 연습실 탐색, 피아노 압박을 지나 **춤추며 문으로 이동하는 60초 탈출 리듬게임**으로 이어집니다.

## 실행과 검사

```sh
cd /workspace/deachung
python3 -m http.server 8000 --bind 0.0.0.0
```

```sh
node --check engine.js
node --check game.js
node tests/game.test.cjs
```

GitHub Pages에서는 `main`의 `/ (root)`를 배포합니다. HTML/CSS/JS와 `assets/`를 함께 배포해야 합니다. 추가 라이브러리는 필요하지 않습니다.

## 진행

1. 스마트폰에서 엄마 메시지 세 개가 순서대로 도착합니다. 답변하거나 아무것도 보내지 않으면 연습실로 들어갑니다. 직접 쓴 말은 전송되지 않고 입력창에 남습니다.
2. 방향키로 이동합니다. 벽과 가구는 통과할 수 없습니다. 물체 가까이 가면 테두리와 이름이 표시됩니다. 클릭하거나 E 키로 가장 가까운 물체와 상호작용합니다.
3. 방에 들어온 뒤 30초에 선생님 알림이 도착합니다. 스마트폰을 열면 기존 두 문장과 추가 질책 아홉 문장이 순서대로 표시됩니다. 읽지 않고 30초가 더 지나면 노크가 시작되고, 이후 10/20/30초마다 경고가 거칠어집니다. 40초에는 엄마의 질책 메시지가 강제로 열리고 게임오버로 이어집니다. 휴대폰을 읽으면 아직 시작되지 않은 노크를 막습니다. 이미 시작된 경고는 피아노에 앉아 중단합니다.
4. 피아노에 앉은 상태에서 선생님 알림이 도착하거나, 알림 뒤 피아노에 앉으면 어두워짐·불안한 독백이 시작됩니다. 압박을 경험하고 일어서면 헤드폰에서 ‘춤을 춘다.’ / ‘춤추지 않는다.’를 선택할 수 있습니다.
5. ‘춤을 춘다.’를 선택하면 기존 연습실 맵에 댄스 준비 화면이 열립니다. 출발 버튼으로 기존 음악 `The Finish Line — Televisions`의 60초 구간을 재생합니다. 로드 실패 시 오류와 재시도 버튼을 표시합니다.
6. Space 또는 판정 레인 터치로 일반 음표를 맞힙니다. 성공할 때마다 스텝·회전·발 구르기와 함께 피아노 근처에서 왼쪽 아래 문까지 이동합니다. 미리 정의한 경로는 피아노·탁자·가방·소파를 피합니다. 캐릭터 위치와 거리 진행바는 같은 보간된 진행률을 사용합니다.
7. **96회 성공하면 문까지 이동**합니다. 전체 일반 음표 중 일부를 놓쳐도 도착할 수 있습니다. 4초마다 정박·엇박자·싱코페이션·쉼표·짧은 연타·셋잇단음이 교대하며 후반에는 0.125초 연타까지 등장합니다. 현재 패턴 이름을 HUD에 표시합니다. 노트 낙하 시간은 1.4초입니다. 판정 범위는 ±120ms, 정확한 판정은 ±45ms입니다. 60초가 끝나야 탈출 선택지가 열립니다. 도착하지 못했다면 즉시 게임오버 대신 춤 재도전 또는 연습실 복귀를 선택합니다.
8. 10/20/30/40/50초에는 빨간 방해음표가 판정선에 도착합니다. 누르지 않고 보내야 합니다. 앞뒤 일반 음표와 판정이 겹치지 않습니다. 누르면 감시카메라의 붉은 시선, 노크·알림, 짧은 경고와 일시적인 음악 감쇠가 발생합니다. 5회 오입력하면 게임오버입니다.
9. 문 앞에 도착하고 60초를 버티면 ‘문을 연다.’ / ‘다시 피아노로 돌아간다.’를 선택합니다. 문은 안쪽 비상 잠금으로 열 수 있습니다. 문을 열면 픽셀 문 개방과 퇴장, 피아노 잔향의 감쇠, 침대 위에서 꿈을 깨는 장면으로 이어집니다. 잠에서 깬 뒤 엄마의 메시지가 다시 도착하고, 새 선택지 ‘아니, 오늘은 밖으로 나가서 춤출거야.’를 고르면 `ENDING. DANCE`로 끝납니다. 기존 긍정 답변·직접 입력·침묵도 유지되며 새 선택지는 꿈에서 깬 뒤에만 나타납니다. 피아노로 돌아가면 다시 헤드폰으로 탈출을 시도할 수 있습니다.

## 조작·오디오·접근성

- 방 이동: 방향키. 가까운 물체: E 또는 클릭. 피아노: A S D F G H J K. 댄스: Space 또는 레인 터치. 일시정지: P.
- Escape로 물체 설명·스마트폰을 닫거나 피아노에서 일어납니다. 탈출 선택지는 버튼으로 결정합니다. Tab/Enter로 버튼을 사용할 수 있습니다. 텍스트 입력 중에는 게임 단축키가 작동하지 않습니다.
- 탭을 떠나거나 창 포커스를 잃으면 자동으로 일시정지됩니다. 정지 중에는 사건·노트·이동·오디오 시간이 진행되지 않습니다. 재시작은 경고·진행률·오입력·알림·입력 상태·예약된 볼륨 변화를 초기화합니다.
- 브라우저 정책상 첫 클릭/키 입력 후 오디오가 활성화됩니다. 상단 소리 버튼으로 음소거합니다. 실제 플레이 시간에 맞춰 초침이 반복되며 문 밖으로 나간 뒤와 엔딩에서는 멈춥니다.
- 노크는 `assets/door-knock.mp3`를 사용하고 로드 실패 시 합성음으로 대체합니다. 배경곡은 `assets/the-finish-line-televisions.mp3`입니다. 효과음·피아노는 Web Audio로 합성합니다. 선생님의 경고는 텍스트와 효과음이며 녹음된 목소리는 없습니다.
- 과도한 점멸·스트로브를 사용하지 않습니다. ‘동작 줄이기’와 OS 설정은 춤 회전·바운스·기타 CSS 애니메이션을 줄입니다. 진행에 필요한 노트 낙하와 경로 이동은 유지됩니다.

## 코드와 검증

- `engine.js`: 결정적 이야기·경고 타이머, 이동 충돌, 노트 판정, 탈출 진행률·경로, 꿈에서 깨어나는 엔딩과 복귀 상태.
- `game.js`: DOM·키/터치 입력, 픽셀맵·춤·카메라·문 렌더링, 오디오와 화면 전환.
- `index.html`, `style.css`: 스마트폰·피아노·댄스 HUD·침실·엔딩 UI.
- `tests/game.test.cjs`: 26개 테스트. 도입부, 경고 단계, 피아노 중단, 빨간 음표 5회 실패, 프레임 독립 이동, 전체 경로 충돌 검사, 96회/60초 성공 조건, 문 열기·기상·엄마의 새 답변·복귀·재도전·초기화를 검증합니다.

Chromium에서도 실제 DOM/키 입력, 음원 디코딩·재생, 탈출 선택지·꿈에서 깨어나는 엔딩·게임오버·재시작과 모바일 화면 폭을 검증했습니다. UI 검증은 빠른 분기 검사와 실제 60초 음악 재생 검사를 구분해서 수행합니다.
